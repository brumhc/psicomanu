# psicomanu

Site profissional de psicologia da Emanuella, com informações sobre
atendimentos para adultos, crianças e adolescentes, nas modalidades online e
presencial.

## Desenvolvimento local

Abra `index.html` no navegador. O site é estático e não precisa de instalação
de dependências ou etapa de build.

## Personalização

Edite `index.html` para atualizar os textos e informações de contato. As fotos
do retrato e do espaço de atendimento ficam em `assets/`; os estilos
responsivos estão em `styles.css`.
